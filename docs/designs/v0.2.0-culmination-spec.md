## 1. Context & Problem Statement

Hermes OS Android (`art.rodriguezrodriguez.hermesos`) is a native Kotlin + Jetpack Compose control plane for a multi-agent Hermes VPS (`lalo-vps`, `aarch64`), optimized for mobile portrait, landscape foldables, and Samsung DeX multi-window desktops.

Through `v0.1.3` (`dbae7af`), the project established:
1. Encrypted cookie/token storage (`EncryptedCookieStore.kt`) and redaction guards (`CredentialGuards.kt`).
2. Connection Ladder probing Tailscale (`http://100.103.166.20:9119`) -> Cloudflare Tunnel (`https://hermes.rodriguezrodriguez.art`) -> Custom URL (`HermesRestClient.kt`).
3. Multiplexed JSON-RPC 2.0 WebSocket client (`HermesRpcClient.kt`) over `WS /api/ws` using single-use 30-second subprotocol tickets (`hermes-gateway-ticket.<ticket>`).
4. Modular Desktop Canvas (`DesktopCanvasScreen.kt`, `DesktopWidgets.kt`), Live Bot Wall merge (`BotWallMerge.kt`), Hosted Bot Team Rooms (`TeamsAndProfilesScreen.kt`), Models/Providers/Config (`ModelsAndProvidersScreen.kt`), MCP Manager (`McpManagerScreen.kt`), Plugin Store (`PluginStoreScreen.kt`), Full-Screen Chat (`ChatScreen.kt`), Contract Diagnostics (`ContractDiagnosticsScreen.kt`), and Jetpack Glance home-screen widgets (`HermesHomeWidgets.kt`).

However, a line-by-line audit of `v0.1.3` against the live Hermes backend (`/home/opc/.hermes/hermes-agent`), stress-tested by two zero-context Goldfish reviewers (`docs/designs/v0.2.0-goldfish-review.md`), reveals **13 concrete wire-contract and transport bugs** (`C1`–`C13`) that cause silent empty lists, HTTP 400/422 failures, loopback auth lockouts, or runtime exceptions, alongside unfinished functional and adaptive-UI milestones required to culminate `v0.2.0`.

### 1.1 Hard Environment & Security Invariants

Every milestone in this specification is bound by the workspace invariants in `AGENTS.md`:
1. **100% Pure Kotlin (`aarch64` headless JDK 17 constraint)**: `lalo-vps` runs `java-17-openjdk-headless` without `javac` or `jlink`, and unit tests execute on pure JVM 17 without Robolectric (`android.util.Base64`, `android.util.Log`, `AudioRecord`, and `AudioTrack` throw `Method ... not mocked` if called directly in unit-tested paths). Introducing any `.java` source file or enabling `buildFeatures.buildConfig = true` breaks `:app:compileDebugJavaWithJavac`. All new code and tests MUST be pure Kotlin (`.kt`).
2. **Compose BOM `2024.06.00` (`material3:1.2.1`) Compatibility**: Experimental Material 3 APIs (`ExposedDropdownMenuBox`, `ModalBottomSheet`) require `@OptIn(ExperimentalMaterial3Api::class)`, and `ExposedDropdownMenuBoxScope` uses zero-arg `Modifier.menuAnchor()` (`MenuAnchorType` does not exist in `1.2.1`).
3. **ARM64 AAPT2 CLI Override Only**: Every Gradle build/test command on `lalo-vps` MUST pass `-Pandroid.aapt2FromMavenOverride=/home/opc/android-sdk/build-tools/aapt2` on the CLI. Never commit this flag into `gradle.properties` (doing so breaks x86_64 GitHub Actions CI).
4. **Zero Committed Secrets**: Never print, hardcode, or commit values from `/home/opc/.hermes/.env`, `auth.json`, `api_keys.txt`, keystores, or GitHub PATs. Masked previews matching `CredentialGuards.isRedactedPreview(...)` must never be echoed back to write endpoints.
5. **Live VPS Service Non-Disruption**: `/home/opc/.hermes/hermes-agent` is strictly read-only. Restarting `hermes dashboard` (`:9119`) is explicitly gated on human confirmation at Review Gate `RG-1` (`STATE.md` Gap #2).

## 2. Goals & Non-Goals

### 2.1 Goals
- **G1 — 100% REST, Loopback Auth & JSON-RPC Wire Contract Alignment (`STATE.md` Gap #1)**: Eliminate all 13 request/response/auth mismatches (`C1`–`C13`) between `HermesRestClient.kt`, `HermesRpcClient.kt`, `CredentialGuards.kt`, `ConnectionNodeScreen.kt`, `ContractDiagnosticsScreen.kt`, and the FastAPI/Gateway schemas in `hermes_cli/web_models.py`, `hermes_cli/web_routers/*.py`, `hermes_cli/web_server_config.py`, `hermes_cli/inventory.py`, and `tui_gateway/contracts/tools_mcp_plugins.py`, verified by deterministic `MockWebServer` unit tests.
- **G2 — Dynamic Plugin Settings Editor & Update Consent/Security Gate (`STATE.md` Gap #3)**: Route profile-scoped plugin discovery and mutations through `WS /api/ws` `plugins.manage` (with REST fallback for `default` when offline), render typed settings forms (`string`, `number`, `boolean`, `enum`, `secret`, `json`) in `PluginStoreScreen.kt`, persist non-secret values with strict JSON types via `plugins.manage` (`action = "settings"`) and secrets via `PUT /api/env`, and implement interactive confirmation dialogs for `consent_required` capability deltas and `scan_blocked` (`caution` vs `dangerous`) verdicts.
- **G3 — Design System Tokens & Theme Migration (`STATE.md` Gaps #8 & #10 / `informe_diseno.md` §§2.1–2.4)**: Establish `ui/designsystem/` (`HermesTokens.kt` semantic colors with authoritative `#00E5C3` `brandTeal`, typography scale, 4dp spacing grid `space0..space7`, and corner radii `none..full`) while keeping existing `ui/theme/HermesTheme.kt` color constants source-compatible during screen migration.
- **G4 — 4-Breakpoint Adaptive DeX Shell, Compact Nav Overflow Fix, Master-Detail Chat & 2D Widget Reorder (`STATE.md` Gaps #9 & #6b / `informe_diseno.md` §§2.1–2.4)**: Provide `LocalHermesWidthClass` once at root `MainActivity` across `COMPACT (<600dp)`, `MEDIUM (600–839dp)`, `EXPANDED (840–1199dp)`, and `LARGE (>=1200dp)`, fix the 9-tab overcrowding in compact `NavigationBar`, fix reactive `focusedScope` + Master-Detail conversation list in `ChatScreen.kt`, and add `packDesktopRows` + 2D `boundsInRoot()` drag-reorder on `DesktopCanvasScreen.kt`.
- **G5 — Opt-In Native Hermes Audio Relay with System Fallback (`STATE.md` Gap #4)**: Add opt-in Hermes server voice mode (`WS /api/audio/transcribe-stream` + `WS /api/audio/speak-stream` authenticated via `?ticket=` / `?token=` + `Origin`, with automatic fallback to `POST /api/audio/transcribe` / `POST /api/audio/speak` and Android `RecognizerIntent` / `TextToSpeech`), controlled from `SettingsScreen.kt` using pure-Kotlin `PcmAudioSource` / `PcmAudioSink` abstractions.
- **G6 — Environment-Driven Release Signing & Regression Suite (`STATE.md` Gap #7)**: Configure optional env-var-driven `signingConfigs.release` (declared before `buildTypes` with `rootProject.file(...)` resolution) in `app/build.gradle.kts`, update app version metadata to `0.2.0` (`versionCode = 2`), and pass `testDebugUnitTest assembleDebug assembleRelease`.

### 2.2 Explicit Non-Goals (Honoring `informe_diseno.md` §4.3 "Qué NO Tocar")
- **NG1**: Do NOT introduce light mode. Hermes OS Android is an OLED-deep dark control center (`#070B12` base).
- **NG2**: Do NOT replace the state management architecture (`StateFlow` + `HermesOsRepository` + `HermesOsViewModel`) with Hilt, Redux, or MVI frameworks, nor introduce KSP/KAPT annotation processors.
- **NG3**: Do NOT alter `BotWallMerge.kt` ("merge, don't clobber"), `EncryptedCookieStore.kt` AES256-GCM encryption, or the Connection Ladder precedence (`Tailscale -> Cloudflare -> Custom`).
- **NG4**: Do NOT implement WebRTC SDP negotiation (`POST /api/audio/voice-live/session` GPT-Live WebRTC) in `v0.2.0`; native PCM/HTTP audio relay (`/api/audio/transcribe*` & `/api/audio/speak*`) + Android system fallback satisfies Gap #4 without bundling a 30 MB `libwebrtc.so` native binary.

### 6.1 Voice Engine Architecture (`feature/voice/HermesAudioRelayClient.kt` + `MainActivity.kt` + `SettingsScreen.kt`)
- **Pure-Kotlin JVM Testability (`GF2-02`)**:
  - `HermesAudioRelayClient.kt` MUST NOT import `android.util.Base64`, `android.util.Log`, `android.media.AudioRecord`, or `android.media.AudioTrack`. Use `java.util.Base64.getEncoder()` / `java.util.Base64.getDecoder()` (RFC 4648 single-line, required by Python `base64.b64decode(..., validate=True)` in `audio.py:104`) and pure-Kotlin `fun interface PcmAudioSource` / `interface PcmAudioSink`, with Android `AudioRecord`/`AudioTrack` adapters confined to `AndroidPcmAudioIo.kt`.
- **Audio WebSocket Authentication & Handshake (`GF1-02`/`GF2-08`)**:
  - Unlike `WS /api/ws`, `WS /api/audio/transcribe-stream` (`audio.py:516-591`) and `WS /api/audio/speak-stream` (`audio.py:593-771`) call bare `await ws.accept()` without echoing `Sec-WebSocket-Protocol`! Passing `Sec-WebSocket-Protocol` fails OkHttp's handshake.
  - Each audio WebSocket open MUST:
    1. Normalize the target scope (`"bot:domo"` -> `"domo"`, `"room:*"` / blank -> `"default"`).
    2. When `authRequired == true`, mint a **fresh single-use ticket** (`POST /api/auth/ws-ticket`) and connect to `wss://.../api/audio/{transcribe|speak}-stream?profile=<encodedProfile>&ticket=<encodedTicket>` with `Origin: <activeBaseUrl>` and **no** `Sec-WebSocket-Protocol` header.
    3. When `authRequired == false` (loopback mode), connect with `?profile=<encodedProfile>&token=<encodedSessionToken>` and `Origin: <activeBaseUrl>`.
- **Lifecycle, Permissions & Fallback (`VoiceTransportMode`)**:
  - `SYSTEM_DEFAULT` (default): Uses Android `RecognizerIntent` + `TextToSpeech`.
  - `HERMES_NATIVE_STREAM` (opt-in toggle exposed via `vm.voiceTransportMode` in `SettingsScreen.kt`):
    - **Permission & Lint Safety**: Check `ContextCompat.checkSelfPermission(context, Manifest.permission.RECORD_AUDIO) == PackageManager.PERMISSION_GRANTED` inline immediately before `AudioRecord(...)` construction (satisfies M6 `:app:lintVitalAnalyzeRelease` `MissingPermission`) and verify `AudioRecord.getMinBufferSize(...) > 0` before recording. Update `MainActivity.audioPermissionLauncher` to branch on `vm.voiceTransportMode.value`, and unify `HermesVoiceService.EXTRA_TARGET_SCOPE` with `MainActivity.EXTRA_FOCUS_SCOPE`.
    - **STT**: Streams 16 kHz `s16le` mono PCM while buffering up to 60 s WAV in memory, updating live `vm.onVoicePartialTranscript(partial)` -> `onVoiceTranscriptReady(final)`. Automatically falls back to `POST /api/audio/transcribe` on WS error/unsupported live STT, and then to `RecognizerIntent`.
    - **TTS**: Streams `WS /api/audio/speak-stream` binary PCM into `PcmAudioSink`; falls back to `POST /api/audio/speak` and finally Android `TextToSpeech` on `{"type": "fallback"}` or network failure. Cancels cleanly in `MainActivity` `DisposableEffect` / `onStop`.
